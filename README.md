Hi! This is Eselanix.
It’s a NixOS-based distribution.
The idea is simple:
it includes features I personally wanted to see, as well as things others might appreciate.
As of Summer 2026, the distro's main highlight is its own custom installer script that simplifies system installation (yes, hello Arch users).
The project is just getting started. I’d welcome any support or feedback.
